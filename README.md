## Technology Stack

- python
- Modular architecture
- CI-ready (GitHub Actions)

## Installation

1. Clone the repository: `git clone https://github.com/yhonaach/OutlineAnnal.git`
2. `cd OutlineAnnal`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure OutlineAnnal, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
